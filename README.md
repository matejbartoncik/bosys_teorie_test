# bosys_teorie_test

PDF soubory jsou kvůli kompatibilitě s Windows (limit délky cesty/názvu při checkoutu) přejmenované na krátký formát `NN.pdf`.

- `NN` odpovídá číslu otázky (např. `13.pdf` = otázka 13).
- Číslo 08 v sadě chybí, protože v původním repozitáři není k otázce 08 samostatný PDF soubor.
